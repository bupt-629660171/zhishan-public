# 知源智膳 · UI 设计方案（草案 v0.1）

> 现状：5 个 Tab、Streamlit 默认样式 + 一块 hero 卡片。功能齐全，但"能看懂"靠用户自己摸索。
> 目标：让第一次用的人，**30 秒内拿到一个可执行的答案**。

---

## 1. 三个可度量的设计目标

| 目标 | 怎么验 |
|---|---|
| 30 秒拿到方案 | 新用户从打开到看见推荐卡片 ≤ 3 次点击 |
| 判定一眼可辨 | 卡片上"能不能吃"不看文字也能认出（颜色+图标+文案三重编码） |
| 手机能用 | 360px 宽下单列可操作，触控目标 ≥ 44px |

## 2. 信息架构：5 个 Tab → 3 个入口 + 更多

现在的 5 个 Tab 是**按功能分的**（方案/记录/查询/反馈/规则），用户是**按场景来的**（今天吃什么 / 查一道菜 / 我吃得对不对）。

```
现在                          改造后
┌─ 生成调养方案          ┌─ 今日（默认）
├─ 两周记录              ├─ 查一道菜
├─ 查询单道菜      →     ├─ 我的记录
├─ 反馈纠错              └─ 更多（规则说明 / 反馈纠错 / 常见疑问）
└─ 规则与合规
```

理由：前三个是高频场景，后两个是低频但必须存在——塞进"更多"，不占主视线。

## 4. 视觉系统

### 色板（判定色是唯一强色）

| 用途 | 色值 | 说明 |
|---|---|---|
| 宜 | `#2E7D5B` 绿 | 主色，也用于品牌 |
| 慎 | `#B8860B` 琥珀 | 提醒，不用红黄纯色 |
| 禁 | `#A33A3A` 砖红 | 错误但不刺眼 |
| 背景 | `#FBFAF7` 暖白 | 比纯白柔和，食养场景 |
| 卡片 | `#FFFFFF` | 1px `#E8E4DC` 边框 |
| 正文 | `#2A2A28` | — |
| 次要 | `#6E6A63` | — |

**不用纯红纯绿**：一是刺眼，二是红色对色弱用户辨识度低——所以判定必须"颜色 + 图标 + 文字"三重编码。

### 字号与间距

- 标题 24 / 卡片标题 18 / 正文 15 / 辅助 13
- 间距 4 的倍数：4 / 8 / 12 / 16 / 24
- 卡片圆角 14，按钮圆角 10

## 5. 组件规范

### 判定徽章（核心组件）

| 档位 | 图标 | 文案 | 底色 |
|---|---|---|---|
| 宜 | 🟢 / ✓ | 适合 | 浅绿 `#EAF4EE` |
| 慎 | 🟡 / ! | 少量 | 浅黄 `#FBF3E2` |
| 禁 | 🔴 / ✕ | 不宜 | 浅红 `#F8EAEA` |

规则：**图标在左、文字在中、永不只靠颜色**。

### 菜品卡

固定结构（顺序不变，降低认知成本）：
1. 判定徽章 + 菜名
2. 性味 · 价格
3. 一句话依据（来自规则 rationale，不超过 40 字）
4. 换一道（最多 2 个，胶囊按钮）
5. 规则依据（默认折叠，点开看编号与出处）

### 状态设计（现在完全没有）

| 状态 | 表现 |
|---|---|
| 空 | "还没有记录，先记 3 天就能看到趋势" + 一个主按钮 |
| 加载 | 骨架屏或进度条（现在只有文字提示） |
| 无结果 | "这个组合下没有可推荐的菜，减少一个忌口试试" + 一键清空忌口 |
| AI 降级 | 不弹错误，用灰色小字："AI 暂时不可用，以下是本地解释" |
| 出错 | 一句人话 + "重试"按钮，不暴露堆栈 |

## 6. 移动端

- 单列布局，卡片占满宽度
- 体质二选一改成上下两个大块（不并排）
- 底部固定主按钮"生成方案"
- 表格（记录页）改卡片列表

## 7. 实施顺序（每步可验收）

| 步 | 内容 | 验收 |
|---|---|---|
| 1 | 设计令牌（颜色/字号/间距）+ 判定徽章组件 | 三个 Tab 都用统一徽章，颜色一致 |
| 2 | 首页重排：体质大按钮 + 忌口 + 主按钮 | 3 次点击内出结果；360px 不横向滚动 |
| 3 | 菜品卡重构（结构固定 + 换一道 + 证据折叠） | 卡片信息层级一眼分清 |
| 4 | Tab 收敛为 3+1，状态补齐（空/加载/无结果/降级） | 每个状态都能手动触发 |
| 5 | 记录页移动化（表格 → 卡片） | 手机上可读 |

## 8. 现状差距

| 问题 | 现在 | 目标 |
|---|---|---|
| 判定表达 | emoji + 文字，颜色弱 | 三重编码，卡片左上固定位置 |
| 页面组织 | 5 Tab 平铺 | 3+1，按场景 |
| 空/错误态 | 几乎没有 | 五种状态齐全 |
| 移动端 | 未适配 | 单列 + 44px 触控 |
| 视觉一致性 | 只有一块 hero CSS | 令牌化 |

## 9. 需要你定的两件事

1. **主场景**：手机（食堂现场）/ 电脑（答辩演示）/ 两者都要
2. **气质**：克制工具感（像查询系统）/ 温暖食养感（像健康 App）

我的建议：**移动优先 + 温暖但克制**——食堂场景一定是手机；答辩时才投屏，
所以"手机上顺"优先，"电脑上大气"其次。
