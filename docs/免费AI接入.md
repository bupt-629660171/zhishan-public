# 免费 AI 接入说明

## 为什么不是"一个免费 AI"，而是三层

没有任何稳定、长期、无门槛的公开免费 API。所以产品上做成三层，每层都能独立工作：

| 层 | 成本 | 是否联网 | 何时用 |
|---|---|---|---|
| **① 模板解释** | 0 | 否 | 默认。用规则依据拼一句话，永远可用 |
| **② 共享额度** | 项目方承担 | 是 | 演示/试用。项目方配置一个 Key，按会话限次 |
| **③ 自带 Key** | 用户承担 | 是 | 重度用户。不满意免费额度时自己接，模型/端点自选 |

三层**都不影响判定**——判定永远由本地规则给出，AI 只负责把理由说顺。

## 配置共享额度（②）

任意 OpenAI 兼容端点都行，写进 `.env`：

```ini
ZY_ACCESS_PASSWORD=你的使用密码
ZY_SHARED_AI_KEY=sk-xxxx
ZY_SHARED_AI_BASE_URL=https://你的端点/v1
ZY_SHARED_AI_MODEL=模型名
ZY_SHARED_AI_LIMIT=20        # 每个会话最多调用次数
```

没配 `ZY_SHARED_AI_KEY` 时，界面里"共享额度"会提示不可用，用户仍可用①和③。

## 可选端点（以官网为准，免费额度会变）

| 提供方 | 特点 | 备注 |
|---|---|---|
| 校内网关 `myai.bupt.edu.cn` | 延迟低、合规、无需公网 | 需要学校分配的 Key，首选 |
| 智谱 GLM-4-Flash | 有免费档 | 中文好，适合解释类短文本 |
| 硅基流动 / 其他聚合 | 有免费小模型 | 注意限速 |
| OpenRouter 免费模型 | 型号多 | 稳定性一般 |

> 不要接"无需 Key 的公开代理"。这类端点随时失效，而且会把请求内容暴露给不明第三方，
> 与「健康类数据不外发」的边界冲突。

## 隐私边界

发送给 AI 的内容只有三样：**菜名、体质标签、规则编号与依据**。

- 不发送问卷原始作答（"容易疲劳""大便黏滞"等）；
- 不发送任何身份信息；
- 不落盘、不记日志。

这条写进了 `shafe_mvp.py` 的 prompt 构造：用户自由文本从不进入 prompt。

## 失败与限流

- 超时 15 秒，失败自动降级到①，页面提示"AI 正在休息"；
- 共享额度用尽，界面提示剩余次数为 0，引导用①或③；
- AI 输出若含穴位/剂量/处方词、与「禁」结论冲突、或出现未放行菜名，**直接丢弃**并降级。

## 成本估算

单次解释约 200~400 tokens。按免费档模型的价格，②层每个会话 20 次调用，
即使全校 1000 人各用满，成本也在可忽略范围——这也是为什么②只做"演示额度"，
不作为长期承诺。
