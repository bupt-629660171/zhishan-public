## 三、仍然存在的风险：git 历史

上面的照片与姓名**存在于历史提交中**（`f470b7b` 等）。即使当前文件干净，任何人 `git log` 仍能看到。

因此公开时**不要直接 push 这个仓库**，而应发布一个"干净仓库"：

```powershell
python scripts/export_public.py      # 导出到 .export/zhishan-public
cd .export/zhishan-public
git init
git add -A
git commit -m "知源食养 v1.0.0"
git remote add origin <你的空仓库地址>
git push -u origin main
```

导出脚本只复制**当前 git 已跟踪**的文件，不含 `.git`、`.env`、`food.db`、照片与任何本地缓存，因此新的提交历史从零开始。

## 四、发布前最终检查（每次发版都跑）

```powershell
python tools.py gate                     # 指标与数据完整性
git grep -n -E '1[3-9][0-9]{9}|[\w.]+@[\w-]+\.[a-z]{2,}' -- .   # 再人工看一眼本机绝对路径
git ls-files | Select-String '\.(jpg|jpeg|png)$'   # 确认只有设计预览图
```

三条都过，再看一眼 `LICENSE` 的数据声明，就可以公开了。
