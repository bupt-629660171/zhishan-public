## 三、关键决策

### 3.1 图鉴为什么按类别分组 + 分页

117 种食材平铺不可用。按"五谷 / 蔬菜 / 肉蛋 / 果品 / 调味 / 其他"分组，解决"找什么"；每页 8 格，解决"看不完"。两者叠加，数量再涨也能用。

### 3.2 判定用"推荐 / 适量 / 暂不建议"，不用"宜 / 慎 / 禁"

"禁"字带着医疗判决的味道。文案层换掉之后，内部规则仍是禁/慎/宜，只是展示口径变了——**数据不动，说法变**。

### 3.3 进度条留在首屏

它是"我今天有没有做点什么"的反馈，和"今天吃什么"同属一个问题链。若哪天觉得抢戏，挪到记录区即可。

### 3.4 游戏化只做"行为反馈"

徽章全部是行为：连续记录、完成今日选择、发现新食材。**没有等级、战力、健康分**——这些会把"饮食参考"变成"健康评分"，越界。
